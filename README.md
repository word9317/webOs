# unNamed OS
unnamed OS is a web-OS made for the stardance hackclub webos project
## It has:
* **Boot Animation:** A sleek, animated intro loading screen on startup.
* **Auto-Launching About App:** Opens up an information window automatically when the OS boots.
* **Notepad:** Features persistent text saving using LocalStorage—your notes stay safe even if you close or refresh the tab.
* **Loading Screen Simulator:** A future GOTY contender (source code included in this repo).

## Installation and local development
For people interested in making their own version of this project
### 1. Clone the repo:
```
git clone https://github.com/word9317/webOs
cd webOs
```
### 2. Running the website
You can also use other methods of self hosting the project, I just prefer using python
```
python3 -m http.server
```
Now the website should be accessible from localhost:8000

### Deployment
Any form of static website deployment works. Currently I use [github pages](https://word9317.github.io/webOs/)
